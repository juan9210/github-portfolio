# assets/

Coloca aquí tus recursos estáticos.

## Foto de perfil

Guarda tu foto como **`profile.jpg`** en esta carpeta:

- Recomendado: imagen **cuadrada**, mínimo **400×400 px**
- Formatos: `.jpg` o `.png` (si usas `.png`, actualiza el `src` en `index.html`)

Aparecerá automáticamente en el hero del sitio con un anillo animado.
Mientras no exista, se muestra un avatar con las iniciales **JC**.

## Archivos actuales

- `favicon.svg` — ícono del sitio (pestaña del navegador)
